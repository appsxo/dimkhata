# DimKhata (ডিমখাতা) — Enterprise Version 🥚

**ব্যবসা প্রতিষ্ঠান:** শরিফ এন্ড ইমান এন্টারপ্রাইজ (Sharif & Eman Enterprise)  
**মালিকদ্বয়:** শরিফ (৬৬.৬৭% / ২ অংশ) এবং ইমান (৩৩.৩৩% / ১ অংশ)  
**ধরণ:** ডিমের আধুনিক পাইকারি ও খুচরা হিসাব সফটওয়্যার (Multi-Branch ERP & POS)  
**ইনফ্রাস্ট্রাকচার খরচ:** **$০.০০ / মাস ($0/mo)** (কোনো পেইড ভিপিএস বা ক্লাউড সার্ভার লাগবে না)  
**টেক স্ট্যাক:** React 19 + TypeScript + Vite (PWA) + Supabase (PostgreSQL 15, Auth, Storage) + GitHub Pages

## 🌟 বাস্তবায়িত ১৫টি মূল ফিচার (All 15 Requirements Implemented)

1. **অটো-জেনারেটেড ইউনিক আইডি আর্কিটেকচার (Unique ID System):**
   - কর্মচারী আইডি: `SE-EMP-001`, `SE-EMP-002`
   - কাস্টমার / পাইকার আইডি: `SE-CUST-001`, `SE-CUST-002`
   - খামারী / মহাজন আইডি: `SE-SUP-001`, `SE-SUP-002`
   - বিক্রয় মেমো আইডি: `SE-INV-2026-0001`
   - ডেলিভারি চালান আইডি: `SE-CHL-2026-0001`
   - ডিম কেনা ভাউচার আইডি: `SE-PUR-2026-0001`
   - খরচের ভাউচার আইডি: `SE-EXP-2026-0001`

2. **কেওয়াইসি ও আইডি সেকশন (KYC Profile & Verification):**
   - ক্লায়েন্ট-সাইড WebP কম্প্রেশন (`5-10 MB` ফোনের ছবি স্বয়ংক্রিয়ভাবে `<60 KB` WebP তে কনভার্ট হয়ে সেভ হয়)।
   - জাতীয় পরিচয়পত্র (NID), পাসপোর্ট, জন্ম নিবন্ধন ও ছবি সুরক্ষিতভাবে সংরক্ষণের ব্যবস্থা।

3. **ফিউচার কোম্পানি স্কেলিং ও শাখা সাপোর্ট (Multi-Branch & Godown):**
   - একাধিক শাখা ও গোডাউন (`SE-BR-001`, `SE-BR-002`) তৈরি ও শাখাভিত্তিক স্টক ট্র্যাকিং।
   - সমন্বিত একত্রিত হিসাব ও শাখাভিত্তিক আলাদা হিসাব দেখার সুইচ।

4. **ইউজার রোল ও সিকিউরিটি কন্ট্রোল (Role-Based Access Control):**
   - **অ্যাডমিন (শরিফ ও ইমান):** লাভ-লোকসান, ২:১ মুনাফা বণ্টন, ব্যাংক ব্যালেন্স, স্টাফ বেতন ও অডিট লগের পূর্ণ এক্সেস।
   - **স্টাফ / ক্যাশিয়ার (`SE-EMP-XXX`):** শুধু ডিম কেনা, বিক্রয় মেমো, চালান, বকেয়া কালেকশন ও স্টক এন্ট্রি। লাভ-লোকসান বা ব্যাংক ব্যালেন্সের তথ্য সুরক্ষিতভাবে গোপন।

5. **প্রতিষ্ঠান ও ব্যাংক একাউন্ট (Company & Banking Profile):**
   - প্রতিষ্ঠানের ব্র্যান্ডিং, লোগো, ঠিকানা দিয়ে অটো ইনভয়েস/মেমো তৈরি।
   - দোকানের ক্যাশ ড্রয়ার, ব্যাংক একাউন্ট (IBBL) এবং মোবাইল ব্যাংকিং (বিকাশ মার্চেন্ট ও নগদ) মূল ক্যাশ বইয়ের (Cashbook) সাথে লাইভ সিঙ্ক।

6. **ডিমের নির্দিষ্ট ৫টি ক্যাটাগরি ও দৈনিক বাজার দর (Product Categories & Dynamic Pricing):**
   - ১. লাল ডিম (ফার্মের)
   - ২. প্যারাগন ডিম
   - ৩. হাঁসের ডিম
   - ৪. কোয়েল পাখির ডিম
   - ৫. দেশি মুরগির ডিম
   - প্রতিদিনের কেনা দর, পাইকারি বিক্রয় দর, খুচরা বিক্রয় দর ও পিস/খাঁচি/শ/হালিতে লাইভ স্টক।

7. **ইনভেন্টরি, ড্যামেজ ও পচা ডিমের হিসাব (Wastage & Expiry Loss):**
   - পরিবহনে ভাঙা বা গরমে নষ্ট ডিম স্টক থেকে মাইনাস এবং স্বয়ংক্রিয়ভাবে ল্যান্ডেড কস্টে "Wastage Loss Expense" হিসাবে লাভ-লোকসানে যুক্ত।

8. **সৌজন্য / গিফটে দেওয়া ডিমের হিসাব (Courtesy Stock Deduction):**
   - স্থানীয় মেহমান বা পরিচিতদের বিনামূল্যে দেওয়া ডিম স্টক থেকে কর্তন এবং আর্থিক মূল্য "Courtesy Expense" হিসাবে লাভ-লোকসানে হিসাব।

9. **সোর্সিং ও ডেলিভারি চালান (Landed Cost & Delivery Challan):**
   - খামার থেকে কেনা দাম + ট্রাক ভাড়া + লোড-আনলোড লেবার খরচ যোগ করে ডিমের প্রকৃত **ল্যান্ডেড কস্ট (Weighted Average Cost - WAC)** হিসাব।
   - বড় অর্ডারের জন্য চালকের নাম, গাড়ির নম্বর ও গন্তব্য ঠিকানাসহ **ডেলিভারি চালান (Delivery Challan)** প্রিন্ট।

10. **বিক্রি ও কাস্টমার ম্যানেজমেন্ট (Wholesale, Retail & Due Track):**
    - পাইকারি ও খুচরা রেটের আলাদা সুবিধাসহ দ্রুত POS মেমো।
    - বাকির সর্বোচ্চ সীমা (Credit Limit) অতিক্রম করলে স্বয়ংক্রিয় লাল সতর্কতা সংকেত।
    - ১-ক্লিকে বাংলা ফরম্যাটে কাস্টমারের **WhatsApp এ বকেয়া তাগাদা মেসেজ ও মেমো পাঠানো**।

11. **কর্মচারীদের বেতন ও অ্যাডভান্স (Payroll Management):**
    - কর্মচারী প্রোফাইল (`SE-EMP-XXX`), মাসিক বেতন, চলতি মাসের অগ্রিম নেওয়া টাকা (Advance) এন্ট্রি।
    - মাস শেষে: `মূল বেতন - অগ্রিম কর্তন = নীট পাওনা` এবং প্রিন্টযোগ্য **বেতন রসিদ (Salary Slip)**।

12. **পরিচালনা ও অন্যান্য খরচ (Operational & Capital Asset Expenses):**
    - স্থায়ী খরচ (দোকান ভাড়া, কারেন্ট বিল)
    - চলতি খরচ (আপ্যায়ন, যাতায়াত, ভ্যান মেরামত)
    - অ্যাসেট কেনা (ডিমের খাঁচি, ডিজিটাল স্কেল, ক্যাশ বাকশো, ফার্নিচার)
    - বিবিধ খরচ (জরুরী ক্যাশ খরচ)

13. **মাস শেষে টোটাল লাভ-লোকসান হিসাব (1-Click Monthly Net Profit & Loss):**
    - মোট বিক্রয় আয় $-$ বিক্রিত ডিমের ল্যান্ডেড কস্ট (COGS) $=$ মোট বাণিজ্যিক লাভ।
    - মোট লাভ $-$ (পরিচালনা খরচ + কর্মচারীদের বেতন + ভাঙা/পচা ক্ষতি + সৌজন্য ডিম) $=$ **প্রকৃত নীট লাভ (Net Profit)**।

14. **২:১ রেশিও অনুযায়ী মালিকদের লভ্যাংশ বণ্টন (Profit Distribution 2:1 Ratio):**
    - **শরিফ (Sharif):** মোট নিট লাভের ২/৩ অংশ (৬৬.৬৭%)।
    - **ইমান (Eman):** মোট নিট লাভের ১/৩ অংশ (৩৩.৩৩%)।
    - (অনুপাতটি Settings থেকে সম্পূর্ণ কনফিগারযোগ্য)।
    - মাস শেষে কোনো মালিকের **ব্যক্তিগত উত্তোলন (Personal Drawings)** থাকলে তা তার প্রাপ্য লভ্যাংশ থেকে কর্তন হয়ে অবশিষ্ট নীট পাওনা প্রদর্শন।

15. **ডাটা ব্যাকআপ ও ক্লাউড সিস্টেম (Cloud + Offline Support):**
    - মোবাইল, ট্যাবলেট এবং কম্পিউটার থেকে ব্রাউজারের মাধ্যমে সরাসরি ব্যবহারযোগ্য (PWA)।
    - ১-ক্লিকে সম্পূর্ণ ডাটাবেজের অফলাইন ব্যাকআপ ডাউনলোড (JSON) ও রিস্টোর।

## 🚀 প্রোডাকশন ডেপ্লয়মেন্ট নির্দেশিকা (GitHub Pages + Supabase)

### ধাপ ১: Supabase ডাটাবেজ সেটআপ (ফ্রি ৫ মিনিট)
1. [supabase.com](https://supabase.com) এ ফ্রি একাউন্ট খুলে একটি নতুন প্রজেক্ট তৈরি করুন (Region: **Singapore `ap-southeast-1`** বাংলাদেশ থেকে সবচেয়ে দ্রুত পিংয়ের জন্য)।
2. Supabase ড্যাশবোর্ডের বাম পাশের মেনু থেকে **SQL Editor** এ যান।
3. নিচের ৩টি মাইগ্রেশন ফাইল ক্রমানুসারে কপি করে রান (Run) করুন:
   - `supabase/migrations/0001_initial_schema.sql` (সকল টেবিল ও ইউনিক আইডি ফাংশন)
   - `supabase/migrations/0002_triggers_and_functions.sql` (WAC ল্যান্ডেড কস্ট ও স্টক ট্রিগার)
   - `supabase/migrations/0003_rls_and_seed.sql` (রো লেভেল সিকিউরিটি ও প্রাথমিক ডাটা)
4. **Project Settings -> API** থেকে **Project URL** এবং **anon public key** কপি করে রাখুন।

### ধাপ ২: গিটহাবে পুশ ও GitHub Pages চালু করা
1. এই রিপোজিটরিটি আপনার GitHub একাউন্টে পুশ করুন:
   ```bash
   git add .
   git commit -m "feat: complete DimKhata enterprise ERP for Sharif & Eman Enterprise"
   git remote add origin https://github.com/<your-username>/DimKhata.git
   git push -u origin main
   ```
2. আপনার GitHub রিপোজিটরির **Settings -> Secrets and variables -> Actions** এ গিয়ে নিচের সিক্রেট দুটি যোগ করুন:
   - `VITE_SUPABASE_URL` : আপনার Supabase URL
   - `VITE_SUPABASE_ANON_KEY` : আপনার Supabase anon key
3. আপনার GitHub রিপোজিটরির **Settings -> Pages** এ যান:
   - **Source** ড্রপডাউনে **GitHub Actions** নির্বাচন করুন।
4. এখন **Actions** ট্যাবে স্বয়ংক্রিয়ভাবে `Deploy DimKhata to GitHub Pages` ওয়ার্কফ্লো রান হয়ে আপনার লাইভ লিংক প্রস্তুত করে দেবে:
   - **লাইভ লিংক:** `https://<your-username>.github.io/DimKhata/`
