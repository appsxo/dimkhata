# DimKhata (ডিমখাতা) 🥚

**প্রতিষ্ঠান:** শরিফ এন্ড ইমান এন্টারপ্রাইজ (Sharif & Eman Enterprise)  
**মালিকদ্বয়:** শরিফ (৬৬.৬৭% / ২ অংশ) এবং ইমান (৩৩.৩৩% / ১ অংশ)  
**লাইভ লিংক:** `https://appsxo.github.io/DimKhata/`  
**টেক স্ট্যাক:** React 19 + TypeScript + Tailwind CSS v4 + Vite (PWA) + Supabase + GitHub Pages

---

## মূল সুবিধাসমূহ (Core Features)
1. **অটো ইউনিক আইডি:** `SE-EMP-001`, `SE-CUST-001`, `SE-SUP-001`, `SE-INV-2026-0001`, `SE-CHL-2026-0001`, `SE-PUR-2026-0001`, `SE-EXP-2026-0001`।
2. **ডিমের ৫টি ক্যাটাগরি ও দৈনিক বাজার দর:** লাল ডিম (ফার্মের), প্যারাগন ডিম, হাঁসের ডিম, কোয়েল পাখির ডিম ও দেশি মুরগির ডিম — খাঁচি, শ, হালি ও পিস এককে লাইভ স্টক।
3. **সোর্সিং ও WAC ল্যান্ডেড কস্ট:** খামারের দর + ট্রাক ভাড়া + লেবার খরচ যোগ করে স্বয়ংক্রিয় গড় কেনা খরচ (Weighted Average Cost) নির্ণয়।
4. **বিক্রয় POS ও ডেলিভারি চালান:** পাইকারি ও খুচরা বিক্রয় মেমো, ডেলিভারি চালান, বাকির সীমা (Credit Limit) সতর্কতা, প্রিন্ট (A4 ও 80mm POS) এবং ১-ক্লিক WhatsApp শেয়ার।
5. **ভাঙা/পচা ও সৌজন্য ডিম:** স্টক থেকে কর্তন এবং স্বয়ংক্রিয়ভাবে লাভ-লোকসানে ক্ষতি হিসেবে হিসাব।
6. **ক্যাশ বুক, ব্যাংক, পে-রোল ও ২:১ লভ্যাংশ বণ্টন:** ক্যাশ ড্রয়ার, IBBL ব্যাংক, বিকাশ ও নগদ সিঙ্ক; কর্মচারীদের বেতন ও অগ্রিম রসিদ; এবং মাস শেষে শরিফ (২ অংশ) ও ইমান (১ অংশ) এর স্বয়ংক্রিয় মুনাফা বণ্টন।
7. **নিরাপত্তা ও ভাষা:** SHA-256 হ্যাশড ৪-সংখ্যার পিন লক (অ্যাডমিন ডিফল্ট পিন: `1234`), বাংলা (ডিফল্ট) ও ইংরেজি ভাষা টগল, এবং Supabase Realtime ক্লাউড সিঙ্ক।

## সেটআপ ও ডেপ্লয়মেন্ট (GitHub Pages + Supabase)

1. **Supabase টেবিল তৈরি:** Supabase SQL Editor-এ [`supabase/schema.sql`](supabase/schema.sql) রান করুন।
2. **GitHub Secrets যোগ করুন:** রিপোজিটরির **Settings → Secrets and variables → Actions**-এ নিচের দুটি সিক্রেট দিন:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
3. **GitHub Pages চালু করুন:** **Settings → Pages → Source: GitHub Actions** নির্বাচন করুন। `main` ব্রাঞ্চে পুশ করলেই স্বয়ংক্রিয়ভাবে লাইভ ডেপ্লয় হবে।
